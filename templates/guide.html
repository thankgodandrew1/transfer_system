User walkthrough

From iMOS export to Transfer News and movement plan.

Generate the verified news first, then compare it with the previous cycle to prepare driver movements. Use sanitized sample files when demonstrating the system publicly.

Workflow one

Generate Transfer News

  1. 01

    Export the four records

    Prepare the current Transfer Management PDF, previous Transfer News PDF, current roster report, and previous roster report.

  2. 02

    Upload and review both rosters

    Check the counts, apparent arrivals/departures, and searchable assignments. No missionary IDs are required. Select a person to correct a role, zone, area or companionship. New roles such as STL/TR are accepted and automatically colour-coded. Confirmed name variations can be linked explicitly instead of being counted as a new arrival and a departure.

  3. 03

    Record emergency transfers and generate

    Choose Previous baseline for emergency transfers that changed the starting assignments before this cycle; choose Current roster for the intended new assignments. Select all companions who share the new assignment. Enter a reason and save. Use Undo if needed, then check the publication details and confirm the rosters before generating.

  4. 04

    Review corrections and warnings

    Inspect the Verification and Changes sheets and any warnings. If verification pauses, return to the saved review to correct assignments and retry. Uploaded originals stay unchanged. After completion, use Start a revised review for further changes; the completed package remains intact. Editing a downloaded workbook does not change the saved review.

  5. 05

    Download and continue the cycle

    Download the ZIP. Keep the updated-roster PDF because it becomes the previous Transfer News input next cycle.

Workflow two

Generate the Transfer Movement plan

Open Movement plan after the current Transfer News has been approved.

  1. 01

    Use the reviewed starting assignments

    From the completed package, choose Prepare movements using these assignments. It supplies the corrected previous baseline and current News automatically. You can still replace either PDF, or paste a Missionary, Zone, Area table if a PDF cannot be parsed. For a later emergency, start a revised review or replace the previous PDF so FROM locations stay accurate.

  2. 02

    Upload the apartment directory

    CSV or XLSX is recommended for office staff. JSON and the legacy Word list also work. Every row needs a Zone, Apartment, and Area.

  3. 03

    Add genuine historical exceptions

    Enter only confirmed exceptions in the form Elder Twum: Anua Obio -> Mbierebe. The normal mapping handles every other change.

  4. 04

    Generate and review

    The system skips new arrivals and released missionaries, groups movements by the previous zone, and stops with an exact list if any transferred area is missing from the directory.

  5. 05

    Give the Word plan to the drivers

    The STATUS cells are intentionally blank. Drivers tick or mark each row only after that missionary has moved successfully. Keep the returned editable directory CSV for the next cycle.
